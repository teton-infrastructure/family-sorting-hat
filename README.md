# The Family Sorting Hat

A fan-made, no-login, static Sorting Hat quiz for the family. Plain HTML/CSS/JS — no framework, no backend.

- Two question sets: **Young wizard** (9 short picture questions; first and last fixed, 7 drawn from a pool of 10) and **Grown-up** (9 questions: 8 drawn from 11, plus a fixed final "the Hat leans in" question). 4 answers each, shuffled every time.
- Each answer adds points to one or two houses. If houses tie, the Hat lets the player choose between only the tied houses.
- Dramatic "hmm… difficult" reveal, original CSS/SVG crests, and a Family Board saved in `localStorage` on the device.
- Optional sound and read-aloud are off by default and only start when tapped.

A fan-made family game. Not affiliated with Warner Bros. or Wizarding World. All questions, art, and code are original.

## Wand Shop
Six kid-friendly picks (wood, core, length, flexibility, handle, sparkly accent) build an SVG wand live: wood color and grain, handle shape, length, bend, bands/gem/vine, and a tip that glows in the house color with a core-specific effect. The Hat suggests picks based on your house; "Surprise me" picks at random. Wands are saved with each person on the Family Board, and can be downloaded as a PNG.
